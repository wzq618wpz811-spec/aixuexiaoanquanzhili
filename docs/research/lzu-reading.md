## 从这些原题得出的设计结论

### 1. 必须把“考查知识”与“答题手势”分开

同样是判断题，可能考可见行为、隐藏状态、管理权限、物性、阈值或应急步骤。原型不能只按原题型批量派发模板。建议至少保存：`source_type`、`knowledge_kind`、`observable_evidence`、`required_context`、`interaction_type`。

推荐规则：可直接看到的行为用对照图；多项独立隐患用多选/热点；不可直接看到的状态先提供标签、审批或设备卡；抽象物性与制度保留文字，图像只辅助；有明确且核验过的先后关系才考虑排序。

### 2. 单幅图的证据能力有限

电源是否隔离、设备是否接地、额定功率、气体成分、化学品相容性、人员资格、实验是否报备，都不能由“看起来像”判定。题干必须提供可追踪事实，AI 生图不能偷偷创造答案条件。无法从题干或图中获知时应视为题目不充分，而不是要求学生猜测。

### 3. 原题里存在“总是/可以/必须”与例外冲突

关闭设备、持续运行、特殊审批等条目需要上下文，不能把它们统一改写为绝对口号。题库治理应支持关联审查：相近知识点、互为例外的条款、不同时间和设备版本放在一起看。自动发现潜在矛盾后交审核者确认。

### 4. 先构建足够的干扰项，再决定是否生图

图片选择应维持同一主体、视角、背景和细节密度，只改变被考查动作。否则学生可以靠“哪张最漂亮/最绿/有笑脸”猜答案。吉祥物可以作为人物主体，但不能用表情或配色泄露正误。看不清防护部件、连接关系时，应优先使用真实规范示意或局部放大。

### 5. 专业题与通识题分层

气瓶固定、通道畅通、权限报告适合多数学生。生物安全柜、特定化学属性、特种设备条目应按学习身份与课程开放。不能因为题库里有就自动推送全校新生，更不能把识别知识升级成实际操作指导。

### 6. 去重与坏题治理要在生图之前

如果未先发现无答案、答案越界、跨页断裂、编号重复、同义重复，生图只会增加坏题成本。建议管线：导入原文 -> 合并跨页 -> 结构完整性检查 -> 知识点/同义聚类 -> 有效性与专业复核 -> 确定呈现模板 -> 生成草图 -> 图文一致性审核 -> 发布。

图像审核要单独检查答案可见性、额外隐患、错误专业细节、吉祥物遮挡、图中不可读文字。文本正确不代表生成图正确。

## 最小模板集合建议

1. 同构图选择：一知识点、一个动作差异。
2. 场景判断：图中提供足够证据，答后解释可见依据。
3. 多热点/多选查隐患：分别判分，记录漏判与误判，避免“随便点全图”。
4. 状态卡分支：包含审批、资格、运行状态或设备标签的上下文。
5. 标签信息比对：文字/SDS/铭牌为证据，图作为载体。
6. 图文辅助知识题：保持原文字题型，解释配图提升理解。
7. 有条件的步骤排序：只用于已审核且具有明确先后约束的内容；保留原题与改编题区分。

这些是基于题目结构的设计建议，不宣称已证明能提高学习效果。需要在真实学生试点中分别测量正确率、解释质量、延后测验保持与教师审题成本。
