# 交小平与交小安配图风格

以 web/assets/offline/wet-hands.png 的原角色和毛绒质感为参考。交小平保留深蓝毛发、奶油色额头条纹和口鼻、棕色眉眼、红鼻、蓝色毛绒爪，日常场景穿素色鼠尾草绿圆领上衣。交小安为橙色毛绒狐狸、橙色爪、奶油色素色上衣。

普通学习、办公室及模拟教具场景不使用帽子、制服、领带、肩章、胸牌。实验防护按具体任务核实，不从角色参考图继承。不得通过服装暗示答案或资质。
