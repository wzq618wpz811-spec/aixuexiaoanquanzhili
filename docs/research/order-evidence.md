# 安全题库排序题：证据范围与启用条件

核查日期：2026-10-09。用途：判断产品是否保留步骤排序交互，并避免把不同含义的“排序”混为一种原始题型。本笔记不提供经过专业审定的安全操作程序。

## 结论

高校实验室安全竞赛确实使用过独立排序题。此次检索尚未取得题干、待排步骤、标准排列均公开的独立排序原题；已取得完整的“从几组步骤排列中选正确一组”的选择题。两种证据不能互相替代。

可以保留排序组件，但按内容审核条件启用，不能为了覆盖交互形式，把检查清单、首要行动题或事故经过强行改成唯一顺序。

## 方法与已检索范围

检索词组超过四组，包括：

- 高校安全题库 + 排序题；实验室安全 + 排序题。
- 实验室题库 + 正确顺序 / 正确次序。
- 报警 + 顺序 + 题库。
- 灭火器 + 使用顺序 + 标准答案。
- 气瓶 + 顺序 + 标准答案。
- 激振器 + 正确顺序 / 标准答案。

优先大学官网。下列明确证据均阅读了网页正文或 PDF 原文；部分网页的网页工具全文查找无返回，已以直接请求原页面并提取正文补充核验。没有把搜索摘要、通用平台功能列表或非官方答案站当作完整原题证据。未发现的结论只限于本次已检索、可公开访问的材料，不代表全国高校从不使用该题型。

## A 类：独立排序题曾被实际使用，但没有取得原题答案

- 不可证实：具体题目内容、步骤数、答案、是否允许部分顺序、是否通过拖动作答。页面没有公开相应题库。

### 泉州职业技术大学

- [能源动态 第二届实验室安全知识竞赛](https://www.qvtu.edu.cn/libr/info/1199/2413.htm)。
- 网页日期：2024-03-13；正文活动时间只写 12 月 15 日，并称对象为 2021 级大一新生，不能直接把网页年份用作活动年份。

## B 类：完整的顺序选择题，可核查原选项和答案

### 过滤除菌顺序题

- [西北大学生命科学学院 219 题页面](https://skjxsf.nwu.edu.cn/ksdh/sysaqks.htm)：通过题干“以下过滤除菌操作的正确顺序是”定位，原文明确标注单选题。本次不提供未经核验的页面全局序号。
- [兰州大学公开题库 PDF](https://caoye.lzu.edu.cn/caoyenew/upload/files/N20210708164726.pdf)：PDF 物理第 55 页，题号 1103；本地 `research/question-banks/LZU.pdf`。
- 结构核验：题干列出 a–d 四项，四个排列选项为 A=abcd、B=adcb、C=abdc、D=adbc；原标准答案 D。
- 两来源是同一道题的重复传播，不算两份独立验证，也不算两个不同交互模板。
- 原题形式是选择一个已有排列；拖动全部步骤是新的改编形式，会改变答题任务及难度。
- 本题涉及专业设备与实验程序；原操作条件和现行 SOP 尚未核验，不作为当前可发布标准步骤。不在本笔记复制实验细节。

## C 类：容易误判为排序、但原题不是排序

| 来源定位 | 实际结构 | 为什么不能直接转换 |
|---|---|---|
| 兰大 PDF 第 61 页第 1151 题 | 单答案选择，要求找不正确陈述；原答案 C | 其中一个选项包含通电、关机的先后关系，但原题整体不要求排列。需确认设备和持续供电例外，才能另建流程题 |
| [内江师范学院消防竞赛题库](https://hxhg.njtc.edu.cn/info/1052/74681.htm)，单选第 3 题；附件答案表 3=A；通知署期 2012-09-19 | 首要行动选择，区分及时报警、延迟报警和仅内部通知 | 只确定某一优先行动，不给出完整应急程序，不能推出报警、撤离、扑救的唯一总顺序 |
| 西北大学 219 题，消防部分第 28 题 | 判断一个含灭火器动作的陈述，原答案为正确 | 流程写在陈述里不等于原题要求排序。改编须明确器型、场景、训练条件与现行要求 |
| 兰大 PDF 第 2 页第 40、54 题 | 判断离室检查或结束工作要求 | 清单里各项可能并列、有例外或由不同人执行，不应把语句排列当唯一操作先后 |
| 事故通报中的时间线 | 事件叙述 | 顺序表示实际发生过什么，可能包含错误行为，不代表正确处置程序 |
| 平台上的“顺序练习” | 按题号或章节依次练习 | 描述题目出现顺序，与题内步骤排列无关 |
| 排行榜、资料排序、问卷偏好排序 | 名次、界面顺序或主观态度 | 不是具有标准操作答案的安全排序题 |
| 通用教学平台支持排序题 | 软件能力清单 | 不能证明某安全题库实际含有排序原题 |

## 建议的启用门槛

1. **原题溯源**：保留原题型、原文、原选项、原答案、定位与版本；改编类型另存，不能覆盖原题身份。
2. **明确先后依据**：逐条记录哪两个动作必须先后，以及依据的现行规程；只有完成清单而无顺序约束时，不启用排序。
3. **条件齐全**：设备类型、参与者资格、任务范围、环境与例外已明确；图片不补造未提供的条件。
4. **并行与分支处理**：允许同时发生的行动不能强制唯一全序。可改用局部先后判断、分支选择或流程阅读。
5. **专业复核通过**：旧急救、危险实验、压力设备等操作程序不因已有题库答案而跳过复核。当前资料只作结构证据。
6. **评估口径分离**：原四选一与改编全排列的答对概率及任务难度不同，正确率分别统计，不能视为等价学习效果指标。
7. **交互可访问**：若采用拖动，同时提供点击移动或键盘调整；这是产品交互要求，不是原题证据。

建议数据字段：

```text
source_question_type
source_question_id / source_locator
source_options / source_answer
adapted_interaction
sequence_basis_reference / sequence_basis_version
required_precedence_pairs
allowed_parallel_groups
scope_and_preconditions
review_status / reviewer / reviewed_at
```

对于第 1103 题，可以在研究数据中记录原排列为 `[a,d,b,c]`，但 `review_status` 应保持待审，不将研究记录误发布为操作指导。

## 当前产品取舍

保留有条件的步骤排序模板。首批内容以真实原题中更充分的单选、判断、多选以及标签/状态卡情境为主。没有取得适合当前学生群体的完整、现行、可审核顺序依据时，排序入口可以暂不分配正式题，而不是制造一套泛用消防或化学操作顺序。
