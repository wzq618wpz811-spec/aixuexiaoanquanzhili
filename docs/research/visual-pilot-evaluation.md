# 真实题视觉设计：第一轮制作、测试与评估

日期：2026-10-09。范围：一次受控研究试验，不是任意输入在线生成系统的验收。

- 15道首批设计、3道补充适配、6道疑题，共24条来源记录，来自4份已经取得的真实题库。记录数含相近知识点，不能当成24个独立知识点。

## 2. 这轮真正执行的生产链

```text
原始文件哈希核验
→ 完整原题与源答案快照
→ 人工策划视觉蓝图与原题映射
→ 内置imagegen实际生成/编辑，或HTML/SVG程序绘制
→ 逐项观察与来源比对
→ 固定底图合成与最终卡片渲染
→ 结构、依赖与证据记录检查
→ 浏览器试答、截图检查与像素比较
→ 研究报告
```

已有14类模板是路由目录。本轮没有为凑齐模板把每题硬套同一种呈现，也没有把完整题目与答案直接交给生图模型自由发挥。

内容规划和原题语义核对由Codex本轮逐题执行；图像也由同一操作者实际查看。尚未实现应用内独立视觉模型盲看、自动语义裁决或任意新题在线改编，不能把本轮人工记录说成自动看图结果。

## 3. 图片检查发现了什么，如何修正

### 关键动作

电话图的手套—听筒、键盘图的手套—按键、清屑图的刷毛—铁屑均有明确接触。清屑角色改为任务工装，工具选项使用毛绒裸手，手拾选项显示灰色手套，避免继承实验服＋蓝手套的通用角色配置。

源题中的作业背景由条件卡给定；没有把手套颜色、污渍或人物穿着当污染史、资格或授权的证明。中文条件、名称与记录字段由程序排版。

图像存在普通电话按键编号等非考查细节；本轮仅核对它们没有成为关键标签、答案或正误线索。不能据此宣称所有提示词中的禁字要求都被逐字严格满足。

### 局部编辑仍发生区域外漂移

以清屑底图为基准，在初次诊断使用的矩形动作区域外比较实际像素；变化像素定义为任一RGB通道差值大于12/255：

| 原始编辑图 | 区域外平均通道差值 | 区域外变化像素比例 |
|---|---:|---:|
| 戴手套手拾 | 2.7044 / 255 | 1.8536% |
| 嘴吹 | 10.3231 / 255 | 11.8022% |

这些值描述指定区域与本轮图片，不是模型总体质量分，也不代表语义错误比例。它们足以说明“保持背景”的提示词不能代替程序锁定背景。

修正方法是用原底图作为完整背景，只在明确的SVG动作区域覆盖编辑变体。原始PNG保持不变。第一版裁剪留下耳部残影，第二版区域纳入完整头部及必要姿态，放大截图复查后未见该残影。

在浏览器中将最终SVG合成按1536×1024原尺寸渲染，并按2像素网格抽样保护区域，排除裁剪边界2像素的抗锯齿带：两个变体各166,995个保护区域样本，变化样本均为0，最大通道差值为0。此结果只证明所测渲染和样本中的背景保持，不证明动作区专业细节天然正确。

### 独立复产的效果

电话与清屑底图各重复生成一次，关键动作证据仍在；人物手侧、背景、机位或道具位置发生变化。它们适合检验动作描述是否复现，不适合作为需要共同背景的对照选项。

2个复产样本不足以估计长期稳定率。当前结论是：动作证据可以复现；对照背景应由共用底图与程序约束保持。

教师研究接口与学生接口隔离，未登录和学生账户不能读取研究原题；公共静态路径不能读取配置答案与原题快照。预反馈载荷没有标准答案、解析或源选项映射；不完整整组请求没有返回答案。

多选必须完整匹配且不得重复、越界。填空仅接受本轮明确记录的等价表述；未知表述返回未确定，不默认判错。简答返回要点自评，`correct=null`，不通过关键词命中制造满分。

执行 `node scripts/verify-visual-pilot-browser.mjs`：18道题在1440、768、390、320四种宽度下共72组检查通过；没有横向溢出或SVG文字越界，实际素材加载成功。

另测试键盘多选与焦点保持、逐题揭晓锁定、整组提交、填空和简答、素材放大、合成选项放大与本地原题对照。查看了桌面、移动与合成放大截图。

历史浏览器回归也通过，覆盖教师/学生隔离、逐题/整组揭晓、鼠标/键盘/触屏拖排与模板页。正式排序内容仍按完整原题及现行先后依据门槛启用；本轮未制作正式排序题。

## 6. 对方案的评估

已经得到实证支持的部分：

- 用真实题的作答语义路由，可保留多选、填空与简答，避免为了图片或按钮改变原题任务。
- 动作图需要具体接触证据；隐藏状态需要可读条件和记录。两类内容分工后，图像与问题的对应比通用站立角色更明确。
- 同场景对照使用共同底图、允许动作区域和程序合成，比独立重生更容易保持一致；本轮测到了原始编辑漂移，也验证了保护区域修正。
- 来源/版本绑定及故障注入能拦截结构错误与过期检查；不能代替专业内容判断。

尚不能据此证明的部分：任意新题自动改编成功率、独立视觉检查器的误检漏检率、长期生图首次合格率、真实学生理解与学习提升、所有学校和任务的现行安全适用性。本轮判断题较多，题型与答案方向分布不是代表性抽样。

本轮方案可用于研究素材与模板制作。正式扩大自动制作前，应增加同类新题及独立检查样本，测试不同人物和任务装备，并做实际学生观察任务。只有新增疑问进入人工内容审核，不把全部日常题变成逐题人工审批流程。
