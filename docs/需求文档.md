## 产品范围
面向大学新生的安全学习与学校题库维护，当前目标为比赛作品和小规模试用。先以开发团队学生验证功能，不将开发者试用当成新生学习成效。

## 本轮对齐
1. 教师端和学生端分别登录，分离导航与接口权限。
2. 教师选择每题确认后公布答案，或整组提交后公布；默认整组。
3. 整组模式可返回修改。逐题模式确认后锁定，避免已知答案后修改计分。
4. 精简界面，只保留必要题干、操作、状态；案例原文与详细说明放入答后解析或教师详情。
5. 题库主题由输入决定；首批案例覆盖实验室管理，不能把题库类型锁死。
6. 取消纯文字学习卡。原始文字题可导入，没有可用视觉设计时进入待处理，不能用装饰图强行发布。
7. 用真实事故通报作为案例依据，严格区分原文事实、教学设问与生成画面。
8. 形象由教师设置，学生统一使用。上传参考图、生成多视图、同题换角色、复用背景、局部重绘均进入技术设计。
9. 本轮实际展示图层替换与手持箱体场景的角色编辑。在线任意输入仍留提供方接口。

## 角色功能
| 教师 | 学生 |
|---|---|
| 导入题库、查看卡片、审核疑题、发布撤回 | 开始/继续练习 |
| 管理角色素材、设置全校形象 | 看图选择、多选、热点、排序、分支 |
| 配置公布方式和每组题数 | 保存答案、回改、提交、查看解析 |
| 查看实际学习记录汇总 | 查看历史、错题再练 |

## 卡片类型
| 类型 | 交互 | 教学用途 |
|---|---|---|
| 图片选择 | 两个视觉情境中选择 | 比较条件差异，例如交接安排 |
| 情境判断 | 根据场景判断说法 | 区分外观正常与手续/依据完整 |
| 情境多选 | 识别多个正确条件 | 设备状态、责任交接共同判断 |
| 热点找隐患 | 点选图片区域，提供等价按钮 | 定位需核查位置，避免只猜文字 |
| 事件排序 | 移动事件卡片 | 还原已核实事件链；不冒充应急操作规范 |
| 分支决策 | 首次选择改变后续情境 | 审批与值守的连续判断 |
| 图文情境 | 有意义的图示＋条件 | 复杂抽象题的备选设计，本轮作为疑题存在 |

不得在答题前用红绿配色或勾叉泄漏答案。图片、文字和交互共同承担信息，不能将文字题仅附一张不相关图片当成完成转换。

## 案例依据
青岛科技大学 2021 年干燥箱事故、西北大学 2024 年过夜实验事故、西南交通大学 2020 年样品包装事故，均有事故学校原通报。卡片为教学改编，不是学校正式原题；AI 图不表示事故现场。出处、事故日期、通报日期、确认事实与信息边界见素材来源文档。

## 内容状态
导入 → 生成 → 自动检查 → 发布或疑题 → 人工修订/退回。缺答案、缺依据、图片缺失、条件冲突、图文不能支持判断时进入疑题。纯文字候选不能人工强行发布。原始题和修订版本分别保留，撤回后不能继续提交旧练习。

本轮自动检查为预先编写的样例结果，不能视为真实模型精度评估。自定义题保留原文并标记待生成/审核。

## 学习会话规则
每组固定题目版本、公布方式和形象版本。教师设置变更仅作用于新组。保存答案与提交判分分离；未完成不能交卷；重复交卷不能重复增加成绩。学生只访问自己的练习。逐题模式允许已确认题的解析可见；整组模式保存接口、恢复接口均不返回答案或判分。

## 形象复用规则
- 正面、侧面、背面等视图是二维素材，不宣称自动得到精确三维模型。
- 简单站立、讲解等场景将背景和角色分层，替换时复用背景及热点布局。
- 握持、接触和遮挡复杂的画面需局部编辑并复核关键动作。
- 更换角色不改变题干、考查点和标准答案；若影响物理动作或可判定条件，应生成新版本并重新检查。
- 场景与角色版本共同形成复用标识，失败结果不能进入发布库。
- 本轮新上传参考图只保存；任意形象视图生成待在线提供方。

## 验收
两端权限隔离；六类交互可用；两种公布策略及中途改设置均符合规则；无纯文字发布；学校形象变更在新练习生效；角色接触姿态的编辑对照可查看；来源可追溯；重复导入/重复交卷不重复计数；桌面和手机可操作。
