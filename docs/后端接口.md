# 知安 v0.2 后端接口
所有写入使用 application/json。教师与学生各自登录，使用角色路径下 HttpOnly Cookie。学生不能读教师接口，旧版无鉴权接口已关闭。

## 教师
| 方法 | 路径前缀 /api/teacher | 请求与返回 |
|---|---|---|
| POST | /login | {password} → role、username |
| GET / POST | /me /logout | 身份 / 退出 |
| GET | /state | 原题、候选、任务、统计、设置、角色、案例 |
| GET | /sample | {text} JSON 样例 |
| POST | /import | {text} → added、duplicates、ids |
| POST | /generate | 可选 {ids} → 202 task |
| POST | /questions/:id/review | action、note；通过需 stem、answer、explanation、sourceUrl |
| POST | /questions/:id/withdraw | 撤回为待审核 |
| POST | /settings | {feedback:batch或each, batchSize, characterId} |
| GET | /characters | 角色列表 |
| POST | /characters | {name,image:data URL} → 参考图档案 |
| POST | /characters/views | {characterId} → 内置角色视图元数据 |
| POST | /characters/replace | {characterId,mode:layer或edit,sceneId:transfer} → 图层或编辑素材 |

自定义角色尚无在线视图生成提供方，不能直接设为学校形象。当前 /characters/views 只返回内置预生成视图，未知角色返回错误；下一阶段改为创建生成任务和轮询。/characters/replace 的 edit 只支持预生成送样场景，不声称泛化编辑。

## 学生
| 方法 | 路径前缀 /api/student | 请求与返回 |
|---|---|---|
| POST | /login | {username,password} |
| GET / POST | /me /logout | 身份 / 退出 |
| GET | /home | 可学卡片数、公布策略、角色、本人会话摘要 |
| POST | /runs | {wrongOnly?:boolean} → 学习会话 |
| GET | /runs/:id | 本人会话；batch 未提交不含答案 |
| POST | /runs/:id/selection | {questionId,selection} → 保存状态；each 可含本题 feedback |
| POST | /runs/:id/submit | 完整交卷 → results；重复请求不重复写成绩 |

练习归属由服务器登录身份决定，不接受 clientId 越权。答案类型见技术设计。整组提交前不会返回完整原题对象、caseInfo 或正确答案。公布方式在开组时冻结。

## HTTP 状态
200/201 成功，202 任务已创建；400 输入或状态不符合，401 未登录，403 跨站写入，404 路由不存在，409 生成队列忙，415 请求格式不支持。应用尚未做完整 OpenAPI/JSON Schema 生成，可在接口稳定后补齐。
