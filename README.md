# 知安 · 校园安全学习

供团队共同查看和试运行的校园安全学习产品。包含教师题库导入、人工审核与发布、学生按专业抽取10题练习、解析、错题重练和学习记录。

形象库：蓝色猫为**交小平**，黄色角色为**交小安**。审核表单无需填写依据网址。

## 下载并运行

1. 安装 Node.js 22.13 或更新版本（建议使用 Node.js 24）。
2. 在 GitHub 点击 **Code → Download ZIP**，下载后解压；也可以克隆本仓库。
3. Windows 用户双击 **启动演示.cmd**。其他系统在项目目录执行以下命令。

```sh
npm start
```

默认端口为4186；如果 `.env` 设置了 `PORT`，以该配置为准。先启动程序，再打开启动窗口实际显示的网址：

- 教师端：http://127.0.0.1:4186/teacher
- 学生端：http://127.0.0.1:4186/student
- 教师登录密码：`123456`
- 学生账号：`student01` 至 `student05`；密码：`123456`，登录时选择专业。

上面的 `127.0.0.1` 指当前电脑，必须先下载解压并启动程序，启动窗口保持运行。直接点击 GitHub 里的本机链接不会自动启动平台。

不需要安装运行依赖，也不需要API密钥或充值。现有题目和配图随仓库提供，在线生成默认关闭。每位队员在自己电脑上运行，学习记录保存在自己的本地数据库中。

如果复制 `.env.example` 为 `.env`，请以其中配置为准：端口仍为4186，教师密码为 `teacher-demo`。真实API密钥只填入自己的 `.env`，不要提交到GitHub。

## 团队协作

查看代码和体验现有题库，可直接使用主分支。修改功能时请创建自己的分支，提交后通过 Pull Request 合并，避免互相覆盖。

```sh
git clone https://github.com/wzq618wpz811-spec/aixuexiaoanquanzhili.git
cd aixuexiaoanquanzhili
git switch -c your-feature
npm start
```

GitHub用于保存、分享代码；本仓库的Node服务和SQLite数据库需在电脑或服务器运行。下载后打开HTML文件不能代替启动程序。

## 数据和配置

- `src/`：后端业务与判分；`web/`：页面及图片；`config/`：题型和场景配置。
- `data/demo.sqlite`：交付时导出的已发布题目；不包含学生作答、任务队列或未审核题。
- `data/question-bank.sqlite`：专业题库资料。
- `.env.example`：空白API配置示例；`.env`、日志、缓存及学生记录不上传。
- 蓝色猫交小平与黄色角色交小安的显示名称已统一。

题目包含原库题与补充课程情境题；具体内容、图片和参考答案仍需教师结合实际教学任务核对。排序题保留步骤核验要求。
